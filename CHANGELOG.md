# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2026-07-29

### Added

- Initial release of Package Ecosystem Visualizer
- Force-directed graph visualization of package dependencies using D3.js
- Support for npm, PyPI, and crates.io registries
- Flask backend serving static files and REST API
- Data integrity verification on startup
- Cached fallback for live data fetches
- Interactive node selection with detail panel
- Filtering by registry, category, popularity, and search
- Dark theme with CSS custom properties
